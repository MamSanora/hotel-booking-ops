ជំហានចុងក្រោយបង្អស់នៃការរៀបចំប្រព័ន្ធនៅលើម៉ាស៊ីនមេ គឺការរៀបចំដើម្បីដាក់ឱ្យដំណើរការជាផ្លូវការ (Deploy) ដោយផ្ទេរគម្រោងប្រព័ន្ធទៅកាន់ក្រុមហ៊ុនផ្ដល់សេវាកម្មអ៊ីនធឺណិត ឬសេវាកម្មបង្ហោះវេបសាយ (ISP - Internet Service Provider)។ យើងមិនចាំបាច់ដំឡើងកម្មវិធី Web Server ថ្មីទៀតនោះទេ ព្រោះយើងមាន Apache របស់ XAMPP រួចរាល់ហើយ ប៉ុន្តែការផ្ទេរកូដ និងប្រព័ន្ធទិន្នន័យពីម៉ាស៊ីនផ្ទាល់ខ្លួន (Local Server) ទៅកាន់ Server របស់ ISP គឺជារឿងដែលត្រូវធ្វើដើម្បីឱ្យប្រព័ន្ធដើរលើអនឡាញបាន។ ដំណើរការនេះរួមមាន៖ ការទិញឈ្មោះវេបសាយ (Domain Registration) ការជួលលំហរផ្ទុក (Web Hosting) ការនាំចេញប្រព័ន្ធទិន្នន័យពី XAMPP ការបង្ហោះឯកសារតាមរយៈ FTP ឬ File Manager ការនាំចូលប្រព័ន្ធទិន្នន័យទៅកាន់ Server របស់ ISP និងការកែសម្រួលកូដភ្ជាប់ទៅកាន់ Database ថ្មី។ ជំហានទាំងនេះមានបង្ហាញក្នុង ឧបសម្ព័ន្ធ ឈ។
៤.៣.១.៨. ការសរសេរកូដ និងការអនុវត្តប្រព័ន្ធ (Code and Implement)
បន្ទាប់ពីបានរៀបចំម៉ាស៊ីនមេ និងឧបករណ៍ជំនួយនានារួចរាល់ ដំណាក់កាលបន្ទាប់គឺការសរសេរកូដបង្កើតប្រព័ន្ធ។ ក្រុមការងារបានប្រើប្រាស់ភាសា PHP សម្រាប់បង្កើត Logic គ្រប់គ្រងផ្នែក Backend និងការចាត់ចែងទិន្នន័យជាមួយ MySQL។ រីឯផ្នែកខាងមុខដែលអ្នកប្រើប្រាស់មើលឃើញ (Frontend) គឺត្រូវបានរៀបចំឡើងដោយប្រើ HTML, CSS, និង JavaScript ដើម្បីឱ្យមានភាពទាក់ទាញ និងងាយស្រួលប្រើប្រាស់។ ជាមួយគ្នានេះ ប្រព័ន្ធ Git ត្រូវបានយកមកប្រើដើម្បីគ្រប់គ្រងកំណែកូដទាំងអស់ ក្នុងន័យធានាសុវត្ថិភាព និងភាពងាយស្រួលក្នុងការតាមដានរាល់ការផ្លាស់ប្តូរ។
៤.៣.២. ការរៀបចំដំឡើងនៅផ្នែកអ្នកប្រើប្រាស់ (Client-Side Installation)
នៅក្នុងផ្នែកនេះ នឹងរៀបរាប់អំពីជំហានចាំបាច់ក្នុងការរៀបចំកុំព្យូទ័ររបស់សមាជិក ឬអ្នកប្រើប្រាស់ (Client) ដើម្បីអាចចូលទៅប្រើប្រាស់ប្រព័ន្ធគ្រប់គ្រងបាន។ ដោយសារប្រព័ន្ធនេះជាប្រភេទ Web Application ដូច្នេះការរៀបចំនៅផ្នែក Client គឺមានភាពងាយស្រួល និងសាមញ្ញជាងខាងផ្នែក Server ឆ្ងាយណាស់។
៤.៣.២.១. ការចូលប្រើប្រាស់តាមរយៈ Web Browser (Access to Web Browser)
បន្ទាប់ពីកុំព្យូទ័រផ្នែក Client មានប្រព័ន្ធប្រតិបត្តិការ Windows 11 រួចរាល់ហើយ ជំហានបន្តគឺការប្រើប្រាស់កម្មវិធីរុករកបណ្ដាញ (Web Browser) ដោយមិនបាច់ដំឡើងកម្មវិធីបន្ថែមអ្វីផ្សេងទៀតឡើយ។ អ្នកប្រើប្រាស់គ្រាន់តែបើកកម្មវិធី Web Browser ណាមួយដែលមាននៅក្នុងម៉ាស៊ីន ដូចជា Google Chrome, Microsoft Edge, ឬ Mozilla Firefox ជាដើម។ បន្ទាប់មក វាយអាសយដ្ឋានគេហទំព័រ (URL) របស់ប្រព័ន្ធដែលបានបង្ហោះនៅលើ Server របស់ ISP នោះវានឹងបង្ហាញផ្ទាំងកម្មវិធីមកភ្លាម។ ជំហាននៃការប្រើប្រាស់ និងការកំណត់នៅលើ Browser មាននៅក្នុង ឧបសម្ព័ន្ធ ដ។ ការរចនាឡើងជា Web Application នេះ ធ្វើឱ្យប្រព័ន្ធមានភាពបត់បែន និងងាយស្រួលប្រើប្រាស់បានគ្រប់ទីកន្លែង ដោយគ្រាន់តែមានអ៊ីនធឺណិត និងកម្មវិធី Browser តែប៉ុណ្ណោះ។
ជំពូកទី ៥
សេចក្តីសង្ខេប សន្និដ្ឋាន និងការផ្តល់អនុសាសន៍ដែលពាក់ព័ន្ធ 
ជំពូកទី ៥សេចក្តីសង្ខេប សន្និដ្ឋាន និងការផ្តល់អនុសាសន៍ដែលពាក់ព័ន្ធ
៥.១. សេចក្តីសង្ខេប
នៅក្នុងការសិក្សាស្រាវជ្រាវ និងការអភិវឌ្ឍគម្រោង «ប្រព័ន្ធដំណើរការកក់សណ្ឋាគារ» សម្រាប់ សណ្ឋាគារ តារាមាស ក្រុមការងារបានសម្រេចជោគជ័យក្នុងការបង្កើតនូវប្រព័ន្ធគ្រប់គ្រងការងារតាមកុំព្យូទ័រមួយ ដែលមានលក្ខណៈទំនើប ងាយស្រួលប្រើប្រាស់ និងមានសុវត្ថិភាពខ្ពស់។ គម្រោងនេះត្រូវបានបង្កើតឡើងដើម្បីដោះស្រាយរាល់បញ្ហាប្រឈមក្នុងប្រតិបត្តិការចាស់ (ការកត់ត្រាដោយដៃ ឬឯកសារកុំព្យូទ័រធម្មតា) ដែលងាយបង្កឱ្យមានការកក់បន្ទប់ស្ទួន ការយឺតយ៉ាវក្នុងការពិនិត្យស្ថានភាពបន្ទប់ កំហុសក្នុងការគណនាប្រាក់ និងហានិភ័យនៃការបាត់បង់ព័ត៌មាន។
ប្រព័ន្ធថ្មីនេះបានប្រមូលផ្តុំ និងសម្រួលកិច្ចការងារស្នូលរបស់សណ្ឋាគារឱ្យមកនៅមួយកន្លែង រួមមាន៖
ការគ្រប់គ្រងបន្ទប់៖ បែងចែកសិទ្ធិប្រើប្រាស់តាមតួនាទី (អ្នកគ្រប់គ្រង និងអ្នកទទួលភ្ញៀវ) និងតាមដានស្ថានភាពបន្ទប់ ព្រមទាំងកំណត់តម្លៃបានច្បាស់លាស់។
ដំណើរការកក់ និងស្នាក់នៅ៖ ជួយឱ្យការកក់បន្ទប់ ការកែប្រែទិន្នន័យ និងដំណើរការចូលស្នាក់នៅ ឬចាកចេញ (Check-in / Check-out) ធ្វើឡើងបានយ៉ាងរហ័ស។
ការទូទាត់ និងការងារផ្ទៃក្នុង៖ គាំទ្រការទូទាត់គ្រប់ទម្រង់ ការចេញវិក្កយបត្រ រៀបចំរបាយការណ៍ចំណូល និងមានប្រព័ន្ធចម្លងទុកព័ត៌មានដើម្បីសុវត្ថិភាព។
៥.២. សេចក្តីសន្និដ្ឋាន
ជាសន្និដ្ឋាន គម្រោងនេះបានឆ្លើយតបយ៉ាងមានប្រសិទ្ធភាពទៅនឹងគោលបំណងចម្បងដែលបានលើកឡើង។ ប្រព័ន្ធថ្មីបានប្តូរការងារទូទៅរបស់សណ្ឋាគារ តារាមាស ឱ្យទៅជាដំណើរការកក់ត្រូវបានកត់ត្រាដោយស្វ័យប្រវត្តិ ដែលជួយកាត់បន្ថយកំហុសឆ្គងអចេតនារបស់មនុស្ស បង្កើនល្បឿនក្នុងការស្វែងរកបន្ទប់ទំនេរជូនភ្ញៀវ និងជួយឱ្យអ្នកគ្រប់គ្រងអាចមើលឃើញពីស្ថានភាពអាជីវកម្ម និងចំណូលប្រចាំថ្ងៃបានភ្លាមៗ ដើម្បីងាយស្រួលក្នុងការធ្វើសេចក្តីសម្រេចចិត្ត។
ទោះបីជាយ៉ាងណាក៏ដោយ ក្នុងដំណាក់កាលបច្ចុប្បន្ននេះ ប្រព័ន្ធនៅមិនទាន់បានភ្ជាប់ទៅនឹងគេហទំព័រកក់បន្ទប់អន្តរជាតិនានា ឬការបញ្ជាឧបករណ៍អគ្គិសនីក្នុងបន្ទប់ដោយស្វ័យប្រវត្តិនោះឡើយ។ ប៉ុន្តែ រចនាសម្ព័ន្ធនៃប្រព័ន្ធនេះត្រូវបានរៀបចំឡើងយ៉ាងមានសណ្តាប់ធ្នាប់ និងមានភាពបត់បែនខ្ពស់ ដែលផ្តល់ភាពងាយស្រួលក្នុងការថែទាំ ក៏ដូចជាការបន្ថែមមុខងារថ្មីៗទៅថ្ងៃអនាគត នៅពេលដែលសណ្ឋាគារមានតម្រូវការរីកចម្រើនជាងនេះ។
៥.៣. ការផ្តល់អនុសាសន៍
ដើម្បីឱ្យប្រព័ន្ធថ្មីនេះដំណើរការកាន់តែមានប្រសិទ្ធភាពខ្ពស់ និងធានាបាននូវនិរន្តរភាពនៃការប្រើប្រាស់នៅក្នុងសណ្ឋាគារ តារាមាស អនុសាសន៍សំខាន់ៗមួយចំនួនត្រូវបានស្នើឡើងដូចខាងក្រោម៖
ការថែទាំ និងពង្រឹងសុវត្ថិភាពជាប្រចាំ៖ ត្រូវត្រួតពិនិត្យដំណើរការប្រព័ន្ធ និងធ្វើការចម្លងព័ត៌មានរក្សាទុកឱ្យបានទៀងទាត់ ដើម្បីការពារហានិភ័យពីការបាត់បង់ទិន្នន័យ ក៏ដូចជាការគ្រប់គ្រងលេខសម្ងាត់របស់បុគ្គលិកម្នាក់ៗឱ្យមានសុវត្ថិភាពខ្ពស់។
ការប្រមូលមតិកែលម្អ៖ គួរបង្កើតការវាយតម្លៃ ឬសួរនាំមតិយោបល់ពីសំណាក់ភ្ញៀវស្នាក់នៅ និងបុគ្គលិកប្រើប្រាស់ផ្ទាល់ ដើម្បីយកព័ត៌មានទាំងនោះមកធ្វើជាមូលដ្ឋានក្នុងការកែសម្រួលរូបរាងកម្មវិធី និងមុខងារនានាឱ្យកាន់តែងាយស្រួលប្រើប្រាស់ជាងមុន។
ការអភិវឌ្ឍបន្ថែមនាពេលអនាគត៖ នៅពេលដែលប្រព័ន្ធបច្ចុប្បន្នដំណើរការបានយ៉ាងរលូន និងមានស្ថេរភាព សណ្ឋាគារគួរពិចារណាពង្រីកសមត្ថភាពប្រព័ន្ធបន្ថែម ដូចជា ការភ្ជាប់ជាមួយគេហទំព័រកក់បន្ទប់ល្បីៗលើពិភពលោក ការបង្កើតប្រព័ន្ធបញ្ជាទិញអាហារសម្រាប់ភោជនីយដ្ឋាន និងការប្រើប្រាស់ប្រព័ន្ធសោទ្វារឆ្លាតវៃ ដើម្បីលើកកម្ពស់ស្តង់ដារសេវាកម្មសណ្ឋាគារឱ្យកាន់តែទំនើប និងអាចប្រកួតប្រជែងខ្ពស់នៅលើទីផ្សារ។

អត្ថន័យនៃពាក្យសំខាន់ៗ
Data: ទិន្នន័យ Input ទៅក្នុង System ដើម្បីធ្វើការគ្រប់គ្រងទិន្នន័យបន្ទប់ ការកក់ និងការទូទាត់។
Database: ទិន្នន័យសំខាន់ៗដែលប្រើប្រាស់ក្នុងប្រព័ន្ធ (MySQL)។
Data Flow Diagram: តារាងលំហូរទិន្នន័យនៃប្រព័ន្ធ (បើមានការលើកឡើង)។
ER Diagram (Entity Relational Diagram): តារាងទំនាក់ទំនងនៃ Entities ក្នុង Database។
Home Page: ទំព័រដើមនៃប្រព័ន្ធ។
React JS: ភាសា/បច្ចេកវិទ្យាសម្រាប់បង្កើត Web Pages (Frontend)។
MySQL: ប្រព័ន្ធគ្រប់គ្រងទិន្នន័យ (DBMS) ដែលប្រើជាមួយ PHP/Laravel។
Password: ពាក្យសម្ងាត់សម្រាប់ការចូលប្រើប្រាស់ (Login)។
System Development Life Cycle (SDLC): វដ្តជីវិតនៃការអភិវឌ្ឍប្រព័ន្ធ (ដែលបានប្រើក្នុងគម្រោង)។
Email: អ៊ីមែលសម្រាប់ការចូលប្រើប្រាស់ (Login)។
Web-based Application: កម្មវិធីដែលដំណើរការតាម Web Browser។
Work Flow Diagram: តារាងលំហូរការងារនៃប្រព័ន្ធ។
Log in: ការចូលប្រើប្រាស់ប្រព័ន្ធ។
Log out: ការចាកចេញពីប្រព័ន្ធ។
Maintenance: ការថែទាំ និងធ្វើបច្ចុប្បន្នភាព (Backup)។
Online: ការភ្ជាប់តាម Internet។
Server: ម៉ាស៊ីនមេសម្រាប់ដំណើរការប្រព័ន្ធ។
Upload: ការផ្ទុកឯកសារ ឬកូដទៅកាន់ Server។
URL (uniform Resource Locator): អាសយដ្ឋាននៃគេហទំព័រ។
User: អ្នកប្រើប្រាស់ប្រព័ន្ធ (Admin, Manager, Receptionist, Guest)។
Web Browser: កម្មវិធីរុករកបណ្តាញ (Google Chrome, Mozilla Firefox ជាដើម)។
Web Page: ទំព័រគេហទំព័រ។
Web Server: ម៉ាស៊ីនមេដែលឆ្លើយតបនឹង Request ពី Client។
Software: កម្មវិធី (Program)។
Username: ឈ្មោះអ្នកប្រើប្រាស់សម្រាប់ Log in។
Dynamic Website: គេហទំព័រដែលអាចធ្វើបច្ចុប្បន្នភាពទិន្នន័យបាន។
Hotel Booking Operation System: ប្រព័ន្ធដំណើរការកក់សណ្ឋាគារ។
RBAC (Role-Based Access Control): ការគ្រប់គ្រងសិទ្ធិតាមតួនាទី (Admin, Manager, Receptionist, Guest)។
Check-in/Check-out: ដំណើរការចូល និងចេញស្នាក់នៅ។
Room Status: ស្ថានភាពបន្ទប់ (Available/Occupied/Dirty)។
Occupancy: អត្រាកាន់កាប់បន្ទប់។
Revenue: ចំណូលពីការកក់ និងសេវាកម្ម។
Dashboard: ផ្ទាំងគ្រប់គ្រងសង្ខេប (Occupancy, Revenue, Booking)។
Backup/Restore: ការបម្រុងទុក និងស្តារទិន្នន័យ។
Laravel + PHP: បច្ចេកវិទ្យា Backend សម្រាប់ប្រព័ន្ធ។
XAMPP: ឧបករណ៍សម្រាប់ដំឡើង Local Server (Apache, MySQL, PHP)។
Git: ប្រព័ន្ធគ្រប់គ្រងកំណែកូដ។
