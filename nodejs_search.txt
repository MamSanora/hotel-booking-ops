JavaScript គឺជាភាសាសរសេរកម្មវិធីដែលត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយក្នុងការអភិវឌ្ឍគេហទំព័រ ដោយវាផ្តល់នូវលក្ខណៈអន្តរកម្ម និងមុខងារដ៏សម្បូរបែបដល់អ៊ិនធឺណិត។ តាមរយៈ JavaScript អ្នកអភិវឌ្ឍអាចបង្កើតបទពិសោធន៍ដែលជាជាមួយនិងការឆ្លើយតបទៅនឹងសកម្មភាពរបស់អ្នកប្រើប្រាស់ ដូចជាការចុចប៊ូតុង ការបំពេញទម្រង់ ឬការរំកិលទំព័រ។ ភាសានេះដំណើរការនៅលើផ្នែកភ្ញៀវ (client-side) ដែលមានន័យថាវាត្រូវបានអនុវត្តដោយកម្មវិធីរុករករបស់អ្នកប្រើប្រាស់ ជំនួសឱ្យម៉ាស៊ីនមេ។ JavaScript អាចធ្វើការជាមួយ HTML និង CSS ដើម្បីកែប្រែរចនាសម្ព័ន្ធនិងរចនាប័ទ្មទំព័រត្រូវបានផ្ទុក គ្រប់គ្រងព្រឹត្តិការណ៍ផ្សេងៗ ផ្ទៀងផ្ទាត់ទិន្នន័យ បង្កើតផែនទី និងក្រាហ្វិកសកម្ម និងធ្វើសំណើទៅកាន់ម៉ាស៊ីនមេដោយមិនចាំបាច់ផ្ទុកទំព័រទាំងមូលវិញ។ លើសពីនេះទៀត JavaScript ក៏ត្រូវបានប្រើប្រាស់នៅលើផ្នែកម៉ាស៊ីនមេ (server-side) តាមរយៈ Node.js ដែលអនុញ្ញាតឱ្យអភិវឌ្ឍកម្មវិធីពេញលេញដោយប្រើភាសាតែមួយ។ ដោយសារតែលក្ខណៈចម្រុះភាពងាយស្រួល និងសហគមន៍អ្នកអភិវឌ្ឍដ៏ធំធេង JavaScript បានក្លាយជាភាសាសរសេរកម្មវិធីដ៏ពេញនិយមបំផុតមួយសម្រាប់ការអភិវឌ្ឍគេហទំព័រ និងកម្មវិធីទូរស័ព្ទចល័ត។

Node.js គឺជាវេទិកាសម្រាប់ដំណើរការ JavaScript នៅក្រៅបរិវេណ Browser (ដូចជាលើ Server) ។ វាប្រើ V8 Engine របស់ Google ដើម្បីអនុវត្តកូដ JavaScript លឿន និងមានប្រសិទ្ធភាព។ Node.js ត្រូវបានគេប្រើប្រាស់យ៉ាងទូលំទូលាយសម្រាប់ការអភិវឌ្ឍន៍៖

៤.៣.១.៤. ការដាក់ដំឡើងកម្មវិធី Node.js
Node.js គឺជា Runtime Environment ដែលអនុញ្ញាតឱ្យភាសា JavaScript អាចដំណើរការនៅផ្នែកខាងម៉ាស៊ីនមេ (Server Side) បាន។ ទោះបីជាប្រព័ន្ធរបស់យើងប្រើប្រាស់ PHP ជាភាសាគោលសម្រាប់ Backend ក៏ដោយ ប៉ុន្តែការមាន Node.js នឹងផ្ដល់ភាពបត់បែនបន្ថែម និងបើកផ្លូវឱ្យយើងអាចប្រើប្រាស់ Tools សម្រាប់ build ផ្នែក Frontend ផ្សេងៗដែលទាមទារឱ្យមាន Node.js ដើម្បីដំណើរការ។ ម្យ៉ាងវិញទៀត វាក៏អាចយកទៅប្រើប្រាស់សម្រាប់កិច្ចការ Scripting ជាក់លាក់ ឬបន្ថែមមុខងារដែលដើរដោយ JavaScript នៅលើ Server បានផងដែរ។ របៀបដំឡើង Node.js ត្រូវបានបង្ហាញយ៉ាងលម្អិតនៅក្នុង ឧបសម្ព័ន្ធ ច។

១. របៀបនិងជំហាននៃការដំឡើង Node.js
ការទាញយកឯកសារដំឡើង៖ ជាកិច្ចការចាប់ផ្ដើមដំបូងបង្អស់ យើងចាំបាច់ត្រូវធ្វើការទាញយកកញ្ចប់កម្មវិធី Node.js ពីគេហទំព័រផ្លូវការតាមរយៈតំណភ្ជាប់ខាងក្រោម៖
លីងសម្រាប់ទាញយក៖ https://nodejs.org/en/download
ដំណើរការជំហានដំឡើង៖ ក្នុងជំហានបន្ត ឱ្យយើងអនុវត្តទៅតាមការណែនាំរបស់ផ្ទាំងកម្មវិធីដំឡើង Node.js ដោយចុចលើប៊ូតុង "Next" ជាបន្តបន្ទាប់ រហូតទាល់តែប្រព័ន្ធបង្ហាញពាក្យថា "install" ទើបយើងចុចទៅលើពាក្យនោះ។
ការផ្ទៀងផ្ទាត់ការដំឡើង៖ ជំហានចុងក្រោយ គឺត្រូវបើកផ្ទាំងកម្មវិធី Command Prompt រួចហើយវាយបញ្ចូលនូវពាក្យបញ្ជា (Command) ថា node --version ដើម្បីធ្វើការត្រួតពិនិត្យ និងផ្ទៀងផ្ទាត់មើលថា តើការដំឡើងកម្មវិធី Node.js របស់យើងទទួលបានជោគជ័យត្រឹមត្រូវហើយឬនៅ។
