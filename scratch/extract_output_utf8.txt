  - ដំណាក់កាលទី១ៈ តម្រូវការ(Requirement)
  - តម្រូវការសម្រាប់ភ្ញៀវ (Guest Requirements): ត្រូវមានប្រព័ន្ធដែលអាចឲ្យភ្ញៀវស្វែងរកបន្ទប់ទំនេរ កក់បន្ទប់ និងទូទាត់ប្រាក់តាម KHQR ដោយខ្លួនឯងបាន ២៤ម៉ោង។ តម្រូវការសម្រាប់បុគ្គលិក (Staff Requirements): ត្រូវការផ្ទាំងការងារ (Dashboard) ងាយស្រួលមើល ដើម្បីចុះឈ្មោះភ្ញៀវចេញ-ចូល (Check-in/out) និងតាមដានស្ថានភាពបន្ទប់ (ទំនេរ, មានភ្ញៀវ, កខ្វក់)។ តម្រូវការសម្រាប់អ្នកគ្រប់គ្រង (Admin Requirements): ត្រូវមានប្រព័ន្ធគ្រប់គ្រងទិន្នន័យបុគ្គលិក កំណត់តម្លៃបន្ទប់ និងអាចទាញយករបាយការណ៍ចំណូលប្រចាំខែបានច្បាស់លាស់។ តម្រូវការទូទៅរបស់ប្រព័ន្ធ (System Requirements): ប្រព័ន្ធត្រូវធ្វើការផ្លាស់ប្តូរទិន្នន័យភ្លាមៗ (Real-time) ដើម្បីការពារបញ្ហាកក់បន្ទប់ជាន់គ្នា (Double-Booking)។

  - ដំណាក់កាលទី២ៈ ការរៀបចំគម្រោង(Design)
  - ការរចនាចំណុចប្រទាក់ (UI/UX Design)៖ រៀបចំគំនូសតាង និងរចនាទំព័រគេហទំព័រសម្រាប់ភ្ញៀវ (Guest Portal) និងផ្ទាំងគ្រប់គ្រងសម្រាប់បុគ្គលិក (Admin Dashboard) ឱ្យងាយស្រួលប្រើប្រាស់។ ស្ថាបត្យកម្មប្រព័ន្ធ (System Architecture)៖ កំណត់រចនាសម្ព័ន្ធសិទ្ធិអ្នកប្រើប្រាស់ (RBAC - Role-Based Access Control) បែងចែកជា Admin, Manager, Receptionist, និង Guest។ មូលដ្ឋានទិន្នន័យ (Database Design)៖ រៀបចំគំនូសតាងទំនាក់ទំនងទិន្នន័យ (ERD) ដើម្បីផ្ទុកទិន្នន័យបន្ទប់ ព័ត៌មានភ្ញៀវ និងប្រវត្តិប្រតិបត្តិការ។ លំហូរទិន្នន័យ (Process Flow)៖ បង្កើតគំនូសតាងលំហូរទិន្នន័យ (Data Flow Diagram - DFD) ដើម្បីបង្ហាញពីដំណើរការនៃការកក់បន្ទប់ និងការបង់ប្រាក់។

  - ដំណាក់កាលទី៣: ការអភិវឌ្ឍន៍(Develop)
  - ជាការដំណាការអភិវឌ្ឍផ្នែកខាងមុខ (Frontend Development)៖ សរសេរកូដបង្កើតចំណុចប្រទាក់អ្នកប្រើប្រាស់ (UI) ដោយប្រើប្រាស់ React.js, HTML, និង Tailwind CSS ដើម្បីឲ្យប្រព័ន្ធមានសោភ័ណភាព និងដើរបានគ្រប់ទំហំអេក្រង់។ ការអភិវឌ្ឍផ្នែកខាងក្រោយ (Backend Development)៖ ប្រើប្រាស់ PHP (Laravel Framework) ដើម្បីសរសេរកូដបញ្ជាដំណើរការទូទៅ ដូចជាការគ្រប់គ្រងទិន្នន័យភ្ញៀវ និងការកក់បន្ទប់។ ការរៀបចំមូលដ្ឋានទិន្នន័យ (Database Implementation)៖ បង្កើតតារាងទិន្នន័យ (Tables) និងភ្ជាប់ទំនាក់ទំនងទិន្នន័យក្នុង MySQL សម្រាប់ផ្ទុកព័ត៌មានប្រព័ន្ធទាំងមូល។ ការភ្ជាប់ប្រព័ន្ធកម្រិតខ្ពស់ (System Integrations)៖ សរសេរកូដភ្ជាប់ប្រព័ន្ធទូទាត់ប្រាក់ KHQR និងបង្កើតក្បួនដោះស្រាយគណនាការកក់លើសចំណុះ (Overbooking Optimization Engine)។

  - ដំណាក់កាលទី៤: ការធ្វើការសាកល្បង(Testing)
  - ការសាកល្បងមុខងារប្រព័ន្ធ (Functionality Testing)៖ ធ្វើការសាកល្បងដំណើរការកក់បន្ទប់ ការទូទាត់ប្រាក់ និងការកត់ត្រាទិន្នន័យ ដើម្បីធានាថាប្រព័ន្ធដំណើរការបានត្រឹមត្រូវ ១០០%។ ការស្វែងរក និងជួសជុលកំហុស (Bug Fixing)៖ ស្វែងរកចំណុចខ្វះខាត និងធ្វើការកែតម្រូវឱ្យបានរួចរាល់ មុននឹងដាក់ប្រព័ន្ធឱ្យសណ្ឋាគារប្រើប្រាស់ជាផ្លូវការ។
